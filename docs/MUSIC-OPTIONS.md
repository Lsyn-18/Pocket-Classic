# 音质与关注歌手

## 使用入口

- 设置 → 音质选择：标准、极高、无损、Hi-Res。中央键确认，勾选表示请求偏好。
- 音乐 → 关注的歌手 → 歌手 → 歌曲。列表底部可继续加载更多；歌曲按网易云热门顺序返回。

歌手来自网易云的收藏/订阅歌手列表，不是社交用户关注列表。空列表时可先到网易云收藏歌手。没有生成或替代私人账号内容；预览检查使用明确标为“示例”的本地测试数据。

## 音质行为

默认标准音质。浏览器使用本地偏好，安卓使用应用 SharedPreferences，并在初次消息桥状态中恢复；登录凭证仍通过 Keystore 加密，与音质设置分开。

选择音质不打断当前歌曲；重新选歌后，在资源解析请求的 level 字段发送 standard、exhigh、lossless 或 hires。后台 Media3 解析后续资源时也读取手机上的偏好。资源可能因账号和歌曲权限回退为较低档位或试听；界面的勾选不宣称已经播放了该音质，不引入其他音源。

## 接口与分页

- GET /api/artists?offset=0：对应 artist_sublist，网易云 /api/artist/sublist，每页 50 位歌手。
- GET /api/artist-tracks?id=…&offset=0：对应 artist_songs，网易云 /api/v1/artist/songs，每页 100 首歌曲。
- POST /api/resolve：浏览器增加 quality 参数，返回的 level/bitrate 保留上游实际结果。

安卓为这两条读取路由增加精确白名单，拒绝附加查询字段、负数及越界分页；请求仍在原生完成。每页沿用原始返回条数推进 offset，显示数据过滤重复和无效 ID。页面返回、切换账号后丢弃旧响应，退出账号时清理歌手列表。一次浏览的集合最多保留 5000 项，避免无限扩张。

## 验证边界

69 项 Node 检查和 16 项安卓单元测试、APK 构建与 Lint 通过。检查覆盖音质参数、上游回退结果、订阅歌手、分页、重复数据、旧账号响应及菜单选歌。浏览器实际检查常规字体、音质菜单、选择保存和使用合成数据的歌手/歌曲页面，未检测到 WebGL 或着色器错误。真实账号歌手列表、VIP/Hi-Res 资源和新版安卓真机播放尚未验证，不能从界面检查推断这些结果。
