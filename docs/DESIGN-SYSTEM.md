# Pocket Classic 界面与动效规范

适用于本轮本地设计改进。经典银色/石墨黑外观、蓝色菜单和转轮比例继续作为基础。

## 共享样式

`web-model/design-tokens.mjs` 是 Canvas 与生成 CSS 的公共来源。普通正文 `#1b2b3a`，辅助文字 `#4b6278`，选中条由 `#216db3` 渐变至 `#174f89`，选中正文为白色、辅助文字为 `#edf5ff`。选中态整个渐变区均需满足普通文字 AA 对比要求，不能只测最深的一端。

原生弹窗继续映射主色 `#246ab4`，深色环境使用既有 `#9acbfa`。后续新增原生组件应使用语义颜色，不复制菜单渐变作为所有按钮背景。明暗环境与机身颜色是两项独立偏好。

网页/原生触控操作以 48px/48dp 为目标。LCD 投影内不能容纳此尺寸的精细操作，应提供工具栏入口或展开面板；禁止用相互重叠的透明点击框扩尺寸。

## 组件与状态

- **菜单行**：区分导航、开关、选择值、正在播放与继续加载；普通/大字行高独立定义。长标题保留完整详情入口。
- **列表范围**：本地、已加载歌曲、收藏歌手、当前队列分别说明范围；搜索空结果仅描述已搜索的数据。
- **展开列表**：始终可发现；输入搜索后保留输入焦点；结果携带原列表索引；返回后恢复查询与阅读位置。
- **播放详情**：完整歌名、歌手、专辑、当前状态；有名称和数值语义的进度与系统音量滑块；队列与播放/暂停操作。
- **错误**：阻断错误保留原因与恢复按钮，直到离开、成功或执行恢复；普通完成提示可以自动消失。加载失败不得替换为虚构歌曲。
- **可访问导航**：Canvas 对应语义菜单，显示当前选中项及分页操作；键盘聚焦时呈现可操作列表。播放位置更新不抢夺焦点。

## 动效约束

| 类型 | 时长/行为 | 约束 |
| --- | --- | --- |
| LCD 层级切换 | 160ms，进入/返回相反方向，小幅位移与淡入 | 点击命中立即使用新页面；连续操作从当前画面接续，不排队 |
| 换曲封面 | 220ms，封面区域内小幅过渡 | 歌名、选中歌曲即时更新，不让动画延迟播放 |
| 材质变化 | 最长 300ms，已有材质参数插值 | 反向从当前状态起步，复用纹理与着色器，倒影同步 |
| 阅读展开 | 260ms，从投影 LCD 的实际位置展开并收回 | 模态焦点管理独立于动画；新操作取消旧动画 |
| 3D 封面浏览 | 同时最多五张实体卡片，中心正面、侧面约 40° | 转轮继续直接选择；复用几何，纹理有界，退出释放封面 GPU 资源 |
| 展示运镜 | 7.6 秒，细节取景后回到正面 | 不在日常选歌时启动；支持立即退出、返回及后台终止 |
| 减少动态效果 | 直接使用最终状态 | 不运行菜单、封面、材质、展开的空间动画；保留必要反馈 |

体感沿用已验收的直接跟手规则；转轮操作期间固定姿态与取景。保留仅冷进程显示现有开场的约定。主动展示运镜与日常选歌分离，需用户主动开启，7.6 秒后回到正面。退出按钮、键盘、触摸、安卓返回、切后台均可结束；不改变音乐和播放进度。

## 待验收清单

新画面需在竖屏、横屏、小屏、明暗环境、大字、减少动态效果下实际检查。尤其检查：新工具栏在 320px 宽度下不溢出；三维封面不遮挡标题与按键；手持倾斜时拾取正确；完整歌名可读；TalkBack 可独立完成核心任务。帧率、功耗和温升只能依据目标设备测量，不能由三角形数量或单元测试推断。

## 本地管理与恢复

- 应用内副本与扫描原文件分别标注；容量包含等待删除的副本。批量操作显示已处理/总数和新增、更新、跳过、失败，部分失败保留可展开的逐项原因。
- 移除后 10 秒内可撤销，再删除应用内副本。扫描记录移除始终保留原文件；当前播放项目先换歌再移除。
- 错误组件由结构化原因决定按钮：授权 → 重新连接/本地音乐；网络 → 重试/本地音乐；不可播放 → 下一首或返回；本地访问 → 重新导入；空间不足 → 管理空间。Canvas、语义导航、展开面板使用相同动作定义。
- 系统字体比例用于原生 WebView 阅读文字；大于等于 1.2 时 LCD 同步大字行高。大字偏好继续单独保存；小屏竖屏的大字工具栏使用两行，不缩小点击目标。

## 诊断与降级

体验诊断默认关闭，只保存当前界面会话的汇总数字；禁止将歌曲、查询、账号、文件路径或地址放入诊断。按钮须明确说明开启、关闭并清除、刷新及清除。静态阅读面板和后台不参与帧间隔采样。

连续 45 个有效前台帧的慢帧窗口才触发场景降精度；每个会话只向下调整，避免来回变化。LCD 清晰度独立保留。WebGL 失效转为简洁界面，播放、队列与展开操作继续可用；用户也可主动选择，重新打开恢复三维显示。性能阈值仍需目标手机数据确认。
