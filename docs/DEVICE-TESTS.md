# 安卓真机检查

## 2026-11-07 · 0.4.0 渲染升级验收进度

本轮电脑未检测到已授权的小米手机，真机帧率、内存、触感和传感器复验待重连。以下为浏览器和模拟器结果，不替代真机性能验收。

- 浏览器：银色与黑色主题、360 × 640、432 × 960、800 × 450，中央键进入音乐菜单及 MENU 返回正常。基线与新版的 WebGL 错误和着色器编译错误均为零。渲染计数见 [升级记录](RENDER-UPGRADE.md)。
- Android 15 模拟器：安装 0.4.0 后显示内置新版 LCD、机身和倒影；通过系统输入点击中央键进入音乐菜单，沿转轮滑动切换到每日推荐，再点击 MENU 返回主页。未登录账号，没有请求私人音乐数据。
- 自动化边界：仪器测试通过页面就绪、无溢出及系统电量读取阶段，随后长时间停留在 ActivityScenario.onActivity 的 waitForIdleSync；已停止该次运行，不记为集成测试通过。线程快照证实测试等待的是界面空闲，未观察到着色器错误。模拟器也留有旧版相同等待的线程记录；这不能证明新版不存在性能回退，仍需要真机前后对比。
- 60 项 Node 检查、15 项 Android 单元测试、APK 构建与 Lint 通过。Lint 仍有依赖升级等警告，无错误。
