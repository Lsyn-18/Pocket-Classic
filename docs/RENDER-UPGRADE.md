# 0.4.0 渲染升级

本次只修改共享网页的视觉链路。机身外形尺寸、320 × 240 菜单坐标、转轮步进、点击区域、原生消息桥、网易云客户端、登录会话和 Media3 均保持原实现。安卓构建配置仅递增版本号。

## 材质与建模

- 银色面板：metalness 0.96、roughness 0.46、clearcoat 0.015、anisotropy 0.025。粗糙度贴图绿色通道接近白色，与材质参数相乘后约为 0.42–0.46，避免两次乘法意外变成抛光表面。
- 中央键：metalness 0.93、roughness 0.44，浅碟面和低强度平面 UV 微法线；外圈保持 roughness 0.70 的哑光塑料。
- 黑色面板使用粗糙度 0.52，维持深色金属和暗转轮的层次。抛光只用于细小倒角；未使用大面积透明镀层。
- 微表面 roughness/normal 贴图采用 NoColorSpace、低强度随机噪声，避免强拉丝、规则棋盘和中央键放射纹。
- 模型由 54 个 Mesh、20,010 个三角形变为 64 个 Mesh、23,990 个三角形，增幅约 19.89%。新增装饰的 raycast 均为空操作，点击仍交给原区域。

## LCD 与环境

LCD 默认物理画布为 1280 × 960。报告内存不足 4 GB、少于 4 个逻辑核心，或最大纹理尺寸不足 2048 的设备采用 960 × 720；不支持硬件信息报告时采用默认档位。逻辑尺寸始终为 320 × 240。启用 LinearMipmapLinearFilter，纹理各向异性不超过硬件上限与 8。

`environment.mjs` 生成 1024 × 512 程序化环境，包含顶部冷白、左侧冰蓝、右侧弱暖白柔光和下方暗反射；启动时仅生成一次 PMREM，释放原始环境贴图与生成器。无需外部 HDR、字体、图片或运行时脚本。

`atmosphere.mjs` 提供光池、暗角、低饱和歌曲 ID 强调色和单个 Points 绘制的微粒。浏览器 88 个、安卓 60 个；开启系统减少动态效果后隐藏微粒并停止呼吸。背景位于模型之后并启用深度测试，避免透明背景覆盖 LCD。所有效果保留在原有单次场景渲染中，未引入 composer、额外全屏后期或实时反射渲染目标。

## 基线对比

浏览器打开同一页面并加上 `?visual=baseline`，可切回原几何、材质、环境和 640 × 480 LCD；去掉参数恢复新版。可与相同尺寸、主题、菜单的默认页面对照。

安卓消息桥只信任精确的本地页面地址，因此不增加查询参数。需要安卓基线包时：

```sh
node web-model/build.mjs --android --visual-baseline
```

构建检查后必须恢复正式资源再构建发布包：

```sh
node web-model/build.mjs --publish --android
```

| LCD 物理像素 | 640 × 480 | 1280 × 960 |
| WebGL / shader 错误 | 0 / 0 | 0 / 0 |

这些是页面诊断计数，不代表手机帧率或 GPU 内存占用。浏览器检查银/黑主题、360 × 640 小屏、432 × 960 竖屏、800 × 450 横屏、中央键进入音乐菜单与 MENU 返回。新增回归检查覆盖 LCD 质量档、坐标命中、三角形预算、装饰不拦截点击、真实几何射线、材质和减少动态效果。

本轮小米手机未连接；0.4.0 真机帧率、内存、持续运行与发热尚待验收。0.3.4 的 60.6 fps 结果不作为本版本结论。已生成的 APK 为可供安装验收的 Debug 测试包。
