# 本地音乐

Android 0.7.1 移除「网易云已下载」入口。离线音乐统一放在「音乐 → 手机本地音乐」；0.7.0 通过任意入口导入的文件继续显示和播放，不会删除副本。喜欢的音乐和我的歌单继续分别显示。

## 使用

1. 进入「音乐 → 手机本地音乐」。
2. 选择「扫描手机音乐」读取系统音频库，或选择「导入音乐文件 / 文件夹」。
3. 导入后保存应用内副本，选择歌曲即可离线播放，不需要连接网易云账号或请求在线音源。

支持 MP3、FLAC、M4A、AAC、WAV、OGG、OPUS、AMR 等普通音频及标准 NCM 文件，实际解码能力取决于 Android 系统。小米选择器的「最近」可能不展示 NCM，可从「浏览」进入实际目录。

应用不能直接读取其他应用的私有下载或缓存。仅支持系统音频库和用户通过系统选择器选中的可访问文件，不支持私有 `.uc` 缓存。

## 保存与权限

- 扫描时才请求音乐读取权限。拒绝扫描权限后仍可通过系统选择器导入文件。
- 导入保存完整离线副本，删除原文件后仍可播放；卸载应用或清除应用数据会移除这些副本。
- 扫描发现的文件直接读取原件，原文件需保留且读取权限有效。
- 单个导入文件最多 512 MB，音乐库最多 5,000 首；文件夹包含最多八层子目录。
- 标准 NCM 首次播放时在本机准备音频缓存，重新准备也不需要网络。

播放时右上角显示双竖杆，暂停时显示三角，点击切换状态。

0.7.0 曾使用原创静音 WAV 与标准 NCM 样本在小米 Android 16 验证系统选择器导入和原生播放；独立回归移除原文件后从副本播放，在线解析和音频 HTTP 请求为 0。0.7.1 的菜单回归同时包含旧类别的导入记录，验证其继续在统一列表显示和按正确队列位置播放。
