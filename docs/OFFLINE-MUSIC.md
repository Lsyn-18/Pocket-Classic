# 离线音乐

Android 0.7.0 的音乐菜单分别提供「喜欢的音乐」「我的歌单」「网易云已下载」「手机本地音乐」。喜欢的音乐按账号读取并分页；我的歌单不再重复包含自己的喜欢列表。

## 网易云已下载

1. 进入「音乐 → 网易云已下载」。
2. 选择「扫描网易云下载」，读取系统音频库中能识别为网易云来源的普通音频；或选择「导入音乐文件 / 文件夹」，在系统选择器中找到下载目录。
3. 导入普通音频或标准 `.ncm` 文件。导入后保存应用内副本，选择歌曲即可离线播放，不需要连接网易云账号或请求在线音源。

小米系统选择器的「最近」可能不展示 NCM；可从「浏览 → 内部存储 → Download」或实际下载目录寻找。Android 限制其他应用读取网易云的私有目录；只存在于网易云内部的缓存、不可选择的下载文件，需先通过网易云支持的方式导出到可访问位置。本版支持标准 NCM 文件，不支持直接读取私有 `.uc` 缓存，也不保证兼容所有网易云版本的下载封装。

## 手机本地音乐

进入「音乐 → 手机本地音乐」，扫描系统音频库，或导入音乐文件 / 文件夹。普通导入音频只出现在此列表；从网易云入口导入的音频归入网易云列表，标准 NCM 自动归入网易云列表。同一文件重新导入另一个入口时更新归属。

支持 MP3、FLAC、M4A、AAC、WAV、OGG、OPUS、AMR 等，实际解码能力取决于 Android 系统。扫描按目录和系统记录的来源区分，来源信息不足时可能需要手动导入到正确入口。

## 保存与权限

- 扫描时才请求音乐读取权限。拒绝扫描权限后仍可通过系统选择器导入文件。
- 导入保存完整离线副本，删除原文件后仍可播放；卸载应用或清除应用数据会移除这些副本。
- 扫描发现的文件直接读取原件，原文件需保留且读取权限有效。
- 单个导入文件最多 512 MB，音乐库最多 5,000 首；文件夹包含最多八层子目录。
- 标准 NCM 首次播放时在本机准备音频缓存，重新准备也不需要网络。

播放时右上角显示双竖杆，暂停时显示三角，点击切换状态。

## 验证范围

小米 Android 16 真机使用原创静音 WAV 与标准 NCM 样本验证：系统文件选择器导入、列表隔离、文件夹取消、原生播放均通过。独立回归删除测试原文件后从保存副本播放两种文件，在线解析和 HTTP 音频请求均为 0。没有取得用户真实网易云下载样本，私有缓存及其他封装未计作通过。
